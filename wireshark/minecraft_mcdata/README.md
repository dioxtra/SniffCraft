# Minecraft protocol definitions

The ``.mcdata`` files are Lua versions of the ``protocol.json`` files of
[PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data), generated by
[tools/gen_mcdata.py](../../tools/gen_mcdata.py) (the commit they come from is written at the top of each file).
``minecraft.lua`` loads the one matching the protocol version of each connection.
